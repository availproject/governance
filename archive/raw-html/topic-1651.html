Avail Transparency Report 14: Increased Block Size to 4MB & Max DA tx size to 1MB

Governance V1 Avail Transparency Report

Report Author: Toufeeq

Execution Details: Changes will be applied at block #989,865

Technical Committee Consensus: 5/7 signers Subscan | Aggregate Substrate ecological network high-precision Web3 explorer

Introduction

This document provides transparency on upcoming or executed network changes. The Technical Committee (TC) has approved increasing the block size from 2MB to 4MB and maximum DA transaction size from 0.5MB to 1MB to meet the growing demand for larger data submissions and optimize blockspace. After assessing their effectiveness, impact, execution feasibility, and security implications, the TC reached a 5/7 majority consensus to proceed with the upgrade.

Proposed / Executed Changes

The proposal was discussed in AIP 6, introduces two key changes:

  1. Block size increase from 2MB to 4MB.

  2. Max DA transaction size (MaxAppDataLength) increase from 512KB to 1MB.

Potential Merits to the Network

  • Increased scalability: Supports higher data throughput without degrading network performance.
  • Improved efficiency: Larger transactions reduce fragmentation and optimize blockspace usage.
  • Seamless adoption: Testing on Turing testnet confirmed that block propagation and validation remain stable.
  • Future-proofing: Ensures Avail can handle growing data demands while maintaining decentralization and security.
