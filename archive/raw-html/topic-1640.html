Introduction:
This report aims to provide transparency to the Avail community regarding both upcoming and executed network changes. The Avail Technical Committee (TC) has approved a runtime upgrade on Avail Mainnet to increase the ideal_stake to 75% from the current 50%. After a detailed review of the upgrade’s effectiveness, impact, and security, the TC reached a majority consensus (5/7) to proceed with the changes.

Proposed / Executed Changes:

The proposal to increase the ideal_stake to 75% was introduced and discussed in the community through AIP 5. This upgrade also increases the MaxBlockCols limit to 1024, which allows governance to increase the block size up to 32 MB.

Code Modifications:
For those interested, you can review the necessary code modifications in the following PR:

  • PR1

Potential Merits to the Network:

The change to the ideal_stake parameter is applied via a runtime upgrade and does not affect the consensus mechanism or validator operations. The network will continue to function as intended, with no disruptions for participants. This upgrade is aligned with network scaling, ensures sustainable APY, and strengthens network security.
