<h3><a name="p-2787-introduction-1" class="anchor" href="#p-2787-introduction-1" aria-label="Heading link"></a><strong>Introduction</strong></h3>
<p>This document provides transparency on upcoming or executed network changes. The Technical Committee (TC) has approved increasing the <strong>block size from 2MB to 4MB</strong> and <strong>maximum DA transaction size from 0.5MB to 1MB</strong> to meet the growing demand for larger data submissions and optimize blockspace. After assessing their <strong>effectiveness, impact, execution feasibility, and security implications</strong>, the TC reached a <strong>5/7 majority consensus</strong> to proceed with the upgrade.</p>
<h3><a name="p-2787-proposed-executed-changes-2" class="anchor" href="#p-2787-proposed-executed-changes-2" aria-label="Heading link"></a><strong>Proposed / Executed Changes</strong></h3>
<p>The proposal was discussed in <a href="../AIPs/aip-006-increase-block-size-to-4mb-maxappdatalength-to-1-mb.md">AIP 6</a>, introduces two key changes:</p>
<ol>
<li>
<p>Block size increase from <strong>2MB</strong> to <strong>4MB</strong>.</p>
</li>
<li>
<p>Max DA transaction size (MaxAppDataLength) increase from <strong>512KB</strong> to <strong>1MB</strong>.</p>
</li>
</ol>
<h3><a name="p-2787-code-modifications-3" class="anchor" href="#p-2787-code-modifications-3" aria-label="Heading link"></a><strong>Code Modifications</strong></h3>

</ul>
<h3><a name="p-2787-potential-merits-to-the-network-4" class="anchor" href="#p-2787-potential-merits-to-the-network-4" aria-label="Heading link"></a><strong>Potential Merits to the Network</strong></h3>
<ul>
<li><strong>Increased scalability:</strong> Supports higher data throughput without degrading network performance.</li>
<li><strong>Improved efficiency:</strong> Larger transactions reduce fragmentation and optimize blockspace usage.</li>
<li><strong>Seamless adoption:</strong> Testing on <strong>Turing testnet</strong> confirmed that block propagation and validation remain stable.</li>
<li><strong>Future-proofing:</strong> Ensures Avail can handle growing data demands while maintaining decentralization and security.</li>
</ul>
