<p><strong>Introduction:</strong><br>
This report aims to provide transparency to the Avail community regarding both upcoming and executed network changes. The Avail Technical Committee (TC) has approved a runtime upgrade on Avail Mainnet to increase the <strong>ideal_stake</strong> to 75% from the current 50%. After a detailed review of the upgrade’s effectiveness, impact, and security, the TC reached a majority consensus (5/7) to proceed with the changes.</p>
<p><strong>Proposed / Executed Changes:</strong></p>
<p>The proposal to increase the <strong>ideal_stake</strong> to 75% was introduced and discussed in the community through <a href="../AIPs/aip-005-increase-ideal-staking-ratio-to-75.md">AIP 5</a>. This upgrade also increases the MaxBlockCols limit to 1024, which allows governance to increase the block size up to 32 MB.</p>
<p><strong>Code Modifications:</strong><br>
For those interested, you can review the necessary code modifications in the following PR:</p>
<ul>
<li><a href="https://github.com/availproject/avail/pull/650">PR1</a></li>
</ul>
<p><strong>Potential Merits to the Network:</strong></p>
<p>The change to the <strong>ideal_stake</strong> parameter is applied via a runtime upgrade and does not affect the consensus mechanism or validator operations. The network will continue to function as intended, with no disruptions for participants. This upgrade is aligned with network scaling, ensures sustainable APY, and strengthens network security.</p>
<p>If you require any additional resources or information, please feel free to drop comments.</p>
<p>Thank you.</p>
